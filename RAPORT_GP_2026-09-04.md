## Punkt 5 — Stawki wyświetlają się źle

### Przyczyna
Wynagrodzenie zapisywane jako surowy string. "10 PLN" z fragmentu innej liczby. Brak jednostki.

### Zmiana
- **`parseSalary()`** (`pdf-parser.ts`): parsuje do `{ kwota, jednostka, bruttoNetto, podejrzana }`.
  - Rozpoznaje: "X zł brutto miesięcznie", "X PLN/h", "X za godzinę".
  - Sanity: miesięczna < 1000 PLN lub godzinowa < 20 PLN → `podejrzana: true`.
- **`formatSalary()`**: prezentacja z jednostką ("4 806 PLN brutto / mies." lub "31,40 PLN/h brutto — ≈ 5 275 PLN/mies.").
- **Scraper**: zapisuje sformatowaną stawkę, ostrzega gdy podejrzana.
- **Skrypt** `scripts/fix-salary.mjs`: przelicza istniejące rekordy.

### Pliki

## (b) Skrypty naprawcze — do uruchomienia na kopii bazy

Wszystkie skrypty mają tryb `dry-run` (domyślny) i `--run`:

```bash
# 1. Deduplikacja
node --env-file=.env.local scripts/dedup-bases.mjs --report raport-dedup-dry.csv

# 2. Oświadczenia — flagowanie błędnych
node --env-file=.env.local scripts/fix-oswiadczenia.mjs --report raport-osw-dry.csv

# 3. Stawki — re-formatowanie
node --env-file=.env.local scripts/fix-salary.mjs --report raport-salary-dry.csv
```

**Kolejność uruchomienia na produkcji (po akceptacji):**
1. `dedup-bases.mjs --run` (najpierw usunąć duplikaty)
2. `fix-oswiadczenia.mjs --run` (potem flagować oświadczenia)
3. `fix-salary.mjs --run` (na końcu poprawić stawki)
